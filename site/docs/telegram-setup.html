Telegram proxy setup

In-app proxy (no device changes needed)

Telegram has built-in proxy support: Settings → Data and Storage → Proxy Settings (desktop: Settings → Advanced → Connection type) → Add proxy → SOCKS5. Enter host, port 8899, username and password from your Verdy dashboard. Toggle Use proxy on — the header dot turns green when connected.

Which Verdy type

Any type works since Telegram only needs a stable tunnel; Static avoids reconnects, residential blends with normal traffic.

Notes

Telegram proxy settings cover the app only — browsers and other apps are unaffected. Calls also route through the proxy once enabled. If the dot stays red, verify the subscription is active (407 = expired login).
