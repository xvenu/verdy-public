API guide

Authentication

Your proxy login is your API key — HTTP Basic (user:pass) or your dashboard session. These are use-only credentials: proxy traffic plus usage endpoints. System keys are never exposed.

Endpoints

GET  /api/dev/endpoints   all types + hosts for your country
GET  /api/dev/creds       username + per-type endpoints
GET  /api/dev/usage       plan, status, expiry, payment history
POST /api/dev/rotate      rotate proxy password (~5 min to propagate)

Example

curl -u USER:PASS https://HOST/api/dev/usage

Limits

The data plane enforces per-key request rate limits; the usage endpoints are lightweight reads. Rotate keys on suspicion of leak — the old password dies at the next node sync. Full reference with four-language snippets: API portal.
