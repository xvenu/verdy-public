Dashboard guide

Home

Plan, expiry countdown, account status, quick actions (copy proxy, renew, ticket, config download), and your recent activity from the audit trail.

My Proxies

One row per proxy-type endpoint on your login. Search, sort, filter by status, bulk-copy URLs, open a type for credentials, downloads (TXT/CSV/JSON), and per-type connection strings.

Usage

Subscription quotas, renewal dates, payment aggregates by month, and per-subscription bandwidth allocation. Node-level traffic telemetry is marked as pending where it isn't measured yet.

Billing & Transactions

Products with monthly/quarterly/yearly cycles, coupons, order checkout, payment methods, numbered invoices with PDFs, and filterable, exportable transaction history.

Support & API

Tickets with status tracking, API key display with one-click regeneration, and copy-paste snippets. Settings covers password, sessions, and notification preferences.
