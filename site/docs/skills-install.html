Verdy Skills for AI agents

Five executable skill packs — each runs real tools and verifies results, not advice docs: SEO monitoring ($12/mo), ad verification ($12/mo), streaming QA ($15/mo), social monitoring ($15/mo), web scraping ($12/mo). Quarterly −10%, yearly −20%, coupons apply. Proxy-driving packs need an active proxy subscription; API-driving scripts meter normal usage. Buy under Billing → Products.

Install (owners only)

Dashboard → AI Skills → Download your pack (versioned tarball). Extract into your agent's skills directory:

tar -xzf verdy-verdy-web-scraping-v2.0.0.tar.gz -C ~/.claude/skills/   # Claude Code
# others (OpenCode, Cursor, Windsurf): extract to the agent skills dir

Verify (mandatory)

Every pack ships a verify command — run it before building. Example: python3 scripts/doctor.py must print ALL PASS. A red gate means stop and fix; never build on it.

Credentials

Skills never bundle secrets. Export VERDY_API_KEY (dashboard → Scraper API → Keys), plus VERDY_USER, VERDY_PASS, VERDY_HOST (port 8899) for proxy-driving packs.

Example prompts

Each pack ships copy-paste prompts, e.g. "Track my top 20 keywords and alert on any top-3 loss" or "Verify my 5 accounts each exit a distinct IP." Full list inside each SKILL.md.
