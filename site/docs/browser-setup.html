Browser setup

Firefox

Settings → Network Settings → Settings → Manual proxy configuration. HTTP Proxy = your host, port 8899, check "Also use this proxy for HTTPS". First page load prompts for username/password — tick remember. Verify at https://api.ipify.org.

Chrome

Chrome follows system proxy settings (or launch with --proxy-server=http://HOST:8899). Authenticate at the browser prompt with your proxy login. For per-profile isolation, prefer Firefox containers or separate Chrome profiles with their own proxy flags.

Quick check

The IP shown by ipify must match your purchased country. If pages stall, confirm the subscription is active and the country's sync is fresh on the Status page.
