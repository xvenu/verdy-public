Chrome proxy setup

Option A — command-line flag (isolated, recommended)

Launch a dedicated Chrome instance that always uses your proxy:

chrome --user-data-dir=/tmp/verdy-chrome --proxy-server=http://HOST:8899

First page load prompts for username and password — enter your proxy login and tick remember.

Option B — system proxy

Chrome → Settings → System → Open your computer's proxy settings, then follow the Windows, Android, or macOS steps. Every Chrome window shares it.

Option C — proxy manager extension

Extensions like SwitchyOmega or FoxyProxy (from the Chrome Web Store) let you switch between Verdy countries per tab with http://USER:PASS@HOST:8899 profiles. Verify at https://api.ipify.org.

Auth notes

407 means expired subscription or wrong password — check the dashboard, renew, and allow up to 5 minutes for node sync.
