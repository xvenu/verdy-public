Selenium

Browsers can't send proxy passwords in the server flag alone — use an auth extension or a local forwarder. Simplest reliable pattern with Chrome:

from selenium import webdriver
opts = webdriver.ChromeOptions()
opts.add_argument("--proxy-server=http://HOST:8899")
driver = webdriver.Chrome(options=opts)
# authenticate once at startup via the browser auth dialog, or inject
# credentials with a minimal proxy-auth extension (Manifest V3 background
# script calling chrome.webRequest.onAuthRequired with USER/PASS).

Prefer Playwright for new automation — it accepts proxy credentials natively. Use Static or sticky sessions so logins survive navigation.
