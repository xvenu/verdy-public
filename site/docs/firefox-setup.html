Firefox proxy setup

Manual configuration

Settings → scroll to Network Settings → Settings → Manual proxy configuration. HTTP Proxy = your host, port 8899, check "Also use this proxy for HTTPS". SOCKS Host with SOCKS v5 works too. Add localhost, 127.0.0.1 to No proxy for.

Authentication

The first page load asks for username and password — your proxy login. Tick remember so it persists per profile.

Per-profile isolation

Run firefox -P to create profiles (e.g. one per country), each with its own proxy settings and saved credentials. Containers additionally split cookies within one window.

Verify

Visit https://api.ipify.org — the IP must match your purchased country. Persistent 407 means expired subscription: renew in the dashboard.
