Android proxy setup

Wi-Fi proxy (per network)

Settings → Network & internet → Wi-Fi → long-press your network → Modify → Advanced options → Proxy: Manual. Hostname = your Verdy host, port 8899, bypass localhost,127.0.0.1. Save — the first connection prompts for proxy username and password (your Verdy login).

Limits to know

Settings apply per Wi-Fi network only — mobile data ignores them, and some apps (notably Google Play services paths) bypass proxies. For whole-device routing including mobile data, use a proxy-tunneling app or run the workload in an antidetect profile instead.

Verify

Open https://api.ipify.org in Chrome — the IP must match your purchased country.
