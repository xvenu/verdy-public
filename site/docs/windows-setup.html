Windows proxy setup

Manual proxy (Windows 10/11)

Settings → Network & internet → Proxy → Manual proxy setup → Use a proxy server: On. Address = your Verdy host, port 8899. Add localhost;127.0.0.1 to the exception list and Save. Windows prompts for username and password on first use — enter your proxy login.

Scope

This routes system traffic including Edge, Chrome (default profile), and most desktop apps. Firefox can override it with its own settings (guide). Command line tools need explicit flags — see Python and Node.js.

Verify

Open https://api.ipify.org — the IP must match your purchased country.
