MoreLogin proxy setup

Per-profile proxy

New browser profile → Proxy settings → custom proxy → type HTTP (or SOCKS5). Fill host (e.g. rr.usa.proxy.verdy.vernerx.com), port 8899, proxy username and password from your Verdy dashboard. Save, then use the built-in proxy test — it must return your purchased country's IP.

Which Verdy type

Account work belongs on Static (one permanent IP per profile) or sticky sessions (USER_sess-shop1) on residential. Never share one proxy across unrelated profiles.

Rotation

For scraping profiles, use a fresh _sess-<id> per profile run instead of rotating mid-session — mid-session IP changes trigger logouts and bans.
