iPhone proxy setup

Wi-Fi proxy

Settings → Wi-Fi → tap the ⓘ next to your network → scroll to HTTP Proxy → Configure Proxy → Manual. Server = your Verdy host, port 8899, Authentication on with your proxy username and password. iOS prompts for credentials on first use if left blank here.

Limits to know

Entries are per Wi-Fi network and ignored on cellular data. For always-on routing (including 5G), use a proxy-tunneling app or a managed device profile instead of the built-in setting.

Verify

Open https://api.ipify.org in Safari — the IP must match your purchased country.
