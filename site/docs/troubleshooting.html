Troubleshooting

HTTP 407 on every request

Unknown login, wrong password, wrong country, or expired subscription. Check the dashboard status line first; renew if expired and allow up to 5 minutes for node sync. Test verbosely: curl -v -x http://USER:PASS@HOST:8899 https://api.ipify.org and paste the output into a support ticket.

HTTP 429

Per-key edge rate limit. Back off exponentially; do not add threads. If you need more throughput, split across products or contact sales.

Timeouts / connection refused

Check the Status page for stale node sync in your country. If the country is stale, switch country in the dashboard (expiry is kept) and report it.

Exit IP changes mid-session

You are rotating. Pin with _sess-<id>. If a sticky session still flips within a minute, the pool is churning — shorten session reuse or pick Static.

Slow responses

Compare direct timing vs proxied timing, try another country, and check status. Per-exit latency is not yet measured — report numbers and we investigate with real data.

Password stopped working after rotation

Expected for up to 5 minutes (node sync). After that, re-copy from the dashboard — the old value is dead by design.
