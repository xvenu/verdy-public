Proxy setup

Endpoints

Every plan exposes HTTP/HTTPS and SOCKS5 on port 8899. Hostnames follow <type>.<country>.proxy.verdy.vernerx.com, e.g. rr.usa.proxy.verdy.vernerx.com:8899 for rotating residential USA. Exact hosts are listed in your dashboard — copy them from there, not from memory.

Authentication

Proxy-Authorization with your proxy_user / proxy_pass. Unknown or expired logins receive HTTP 407.

Sticky vs rotating

Append _sess-<any-id> to the username to pin an exit IP (e.g. user_sess-shop1). A new id per request rotates. Sticky holds minutes to tens of minutes depending on pool health, not forever — design retries accordingly.

Test command

curl -x http://USER:PASS@HOST:8899 https://api.ipify.org
curl -x socks5://USER:PASS@HOST:8899 https://api.ipify.org

Limits

Per-key request rate limits are enforced at the edge; sustained 429s mean slow down, not retry harder. See Troubleshooting.
