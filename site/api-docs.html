API reference.

Every endpoint below exists in the beta. Base path is your dashboard host; USER:PASS is your proxy login unless noted.

Proxy APIs

Send traffic

# cURL
curl -x http://USER:PASS@HOST:8899 https://api.ipify.org
# Python
import requests
p = {"http": "http://USER:PASS@HOST:8899", "https": "http://USER:PASS@HOST:8899"}
requests.get("https://api.ipify.org", proxies=p, timeout=20)
# JavaScript
const { HttpsProxyAgent } = require("https-proxy-agent");
const agent = new HttpsProxyAgent("http://USER:PASS@HOST:8899");
// Go
proxyURL, _ := url.Parse("http://USER:PASS@HOST:8899")
client := &http.Client{Transport: &http.Transport{Proxy: http.ProxyURL(proxyURL)}}

List endpoints

curl -u USER:PASS https://HOST/api/dev/endpoints
# → {"country": "usa", "endpoints": [{"type": ..., "http": ..., "socks5": ...}]}

Credentials

curl -u USER:PASS https://HOST/api/dev/creds
# → {"username": ..., "password": ..., "endpoints": [...]}

Rotate password

curl -u USER:PASS -X POST https://HOST/api/dev/rotate
# → {"username": ..., "password": "NEW", "note": "old password stops ... 5-min node sync"}

Billing APIs

Create order

curl -b cookies.txt -X POST -d "slug=res-20gb&cycle=monthly&country=usa&ptype=rotating-residential" https://HOST/bx/order
# → {"order_id": "ord_...", "amount_usd": 20.0, "status": "pending"}

Pay

curl -b cookies.txt -X POST -d "order_id=ord_...&method=paystack_card" https://HOST/bx/pay
# methods: paystack_card, paystack_momo, mpesa, usdt, usdc → checkout URL or awaiting instructions

Subscription APIs

Subscriptions surface through GET /api/dev/usage (plan, active, expires_at) and the portal's Usage page (quotas, renewal dates). No separate token model in beta.

Usage APIs

curl -u USER:PASS https://HOST/api/dev/usage
# → {"plan": ..., "active": true, "expires_at": ..., "payments": [...]}

Account APIs

Country and type switches are form endpoints (/switch-country, /switch-type); password change is /change-password. All session-authenticated.

Invoice APIs

Numbered invoices render in Transactions; GET /app/invoice-pdf?number=INV-… downloads the PDF (owner or admin).

Support APIs

Tickets are created via the portal form (POST /ticket: subject, body) with status tracking in Support Center.
